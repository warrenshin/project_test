# ADR 0001: 초기 아키텍처 및 범위 결정

- 상태: 핵심 항목 확정 (Accepted) — 일부 세부 항목은 여전히 대기
- 날짜: 2026-08-16 (2026-08-16 업데이트: 시장 범위·데이터·AI 공급자 확정)
- 근거: `docs/product-spec.md` 10장, 부록 C

## 배경

명세서 부록 C "구현 시작 시 첫 결정 목록"에 따라, 개발 착수 전 확정해야 하는 항목을 정리한다.
명세서가 제시한 기본값(section 10.2)을 채택하되, 제품 범위에 직접 영향을 주는 항목은
사용자 확인이 필요함을 표시한다.

## 결과

시장 범위(한국+미국), 시세 데이터 조달 방식(무료 API 우선), AI 공급자(Anthropic Claude)가
확정되어 Phase 1(인증·DB 마이그레이션)에 이어 Phase 3 설계 시 한국·미국 이중 통화/이중
거래소 지원을 전제로 진행한다. 무료·유료 기능 경계 등 잔여 항목은 계속 대기하며, 콘텐츠·
베타 관련 항목은 해당 Phase 진입 시점에 결정한다.
