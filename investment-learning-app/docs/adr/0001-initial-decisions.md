# ADR 0001: 초기 아키텍처 및 범위 결정

- 상태: 제안됨 (Proposed) — 사용자 확인 필요한 항목은 표시
- 날짜: 2026-08-16
- 근거: `docs/product-spec.md` 10장, 부록 C

## 배경

명세서 부록 C "구현 시작 시 첫 결정 목록"에 따라, 개발 착수 전 확정해야 하는 항목을 정리한다.
명세서가 제시한 기본값(section 10.2)을 채택하되, 제품 범위에 직접 영향을 주는 항목은
사용자 확인이 필요함을 표시한다.

## 결정 사항

| 항목 | 결정 | 상태 |
|---|---|---|
| 모바일 프레임워크 | Flutter | 확정 (명세서 기본값) |
| 관리자 웹 | Next.js + TypeScript | 확정 |
| API 서버 | FastAPI + Python | 확정 |
| DB | PostgreSQL | 확정 |
| 캐시·작업 큐 | Redis + Celery/RQ | 확정 |
| 초기 아키텍처 | 모듈형 모놀리스 + 별도 시장데이터/체결 worker | 확정 (명세서 10.1) |
| 저장소 전략 | 기존 `project_test` 저장소 내 `investment-learning-app/` 하위 신규 폴더로 시작 (모노레포) | 확정 |
| 대상 시장 (한국만 vs 한국+미국) | **미정 — 사용자 확인 필요** | 대기 |

| 수수료·세금·슬리피지 기본 정책 | **미정 — 시장 확정 후 정책 테이블 설계** | 대기 |

| 첫 전문 콘텐츠 트랙 | 후속 버전 (P1) 항목, MVP 이후 결정 | 대기 |
| 폐쇄 베타 모집 방식 | Phase 5 진입 시점에 결정 | 대기 |

## 결과

이번 세션에서는 확정된 항목을 기준으로 저장소 골격과 API 스켈레톤을 우선 구축한다.
대기 항목은 사용자에게 별도로 질의하며, 답변에 따라 이 ADR을 갱신한다.
