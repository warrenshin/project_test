# 모의투자 불변조건 테스트

명세서 14.2 핵심 불변조건을 속성 기반 테스트(property-based test)로 검증한다.

- [x] 매수 체결 후 현금 감소액 = 체결대금 + 모든 비용
- [x] 매도 체결 후 현금 증가액 = 체결대금 - 모든 비용
- [x] 보유수량은 허용하지 않는 한 0 미만이 될 수 없다 (초과 매도 차단)
- [x] 동일 이벤트(Idempotency-Key) 재실행 시 잔고가 다시 변하지 않는다
- [ ] 원장의 이벤트 합계가 항상 일치한다 (속성 기반 테스트로 별도 강화 필요)
- [ ] 미래 가격으로 과거 주문을 체결하지 않는다 (현재는 항상 "최신 bar" 기준이라
      해당 시나리오 자체가 없음 — 과거 시점 재생 테스트가 필요해지는 시점에 추가)
- [ ] 액면분할 전후 총 평가가치는 시장 움직임을 제외하면 보존된다 (기업행사 미구현)

현재는 위 체크된 항목이 `apps/api/tests/test_orders.py`에 통합 테스트(API 호출
기반, 실제 Postgres 대상)로 구현되어 있다. 이 폴더는 도메인 로직만 대상으로 하는
속성 기반(property-based) 테스트를 별도로 추가할 자리로 남겨둔다 — 특히 원장
합계 불변조건과 기업행사 관련 항목은 property-based 테스트(예: Hypothesis)로
다수의 무작위 주문 시퀀스를 검증하는 편이 더 강력하다.
